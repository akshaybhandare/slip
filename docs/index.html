Full-text search indexed by SQLite FTS5 alongside optional natural language semantic search for conversational queries.

Bring Your Own AI (BYO-AI)

Read saved articles cleanly with sanitized HTML, custom typography, zero ads, and no trackers.

Clips & Recycle Bin

Organize into nested collections, with non-destructive recycle protection and instant 6-second undo toast.

100% Self-Hosted & Private

Single SQLite WAL database file running completely on your hardware, Docker, or Unraid server.

Deploy with Docker in Seconds

Run one simple command or use docker-compose to get Slip running locally.

docker-compose.yml
yaml 
services:
  slip:
    image: ghcr.io/akshaybhandare/slip:latest
    container_name: slip
    restart: unless-stopped
    ports:
      - "3000:3000"
    volumes:
      - ./data:/app/data
    environment:
      - PORT=3000
      - NODE_ENV=production
