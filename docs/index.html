Capabilities

Built for clarity and efficiency

Orderful Masonry Stream

High-density stream masonry organizing articles, videos, product clips, and notes with zero layout shifting.

Dual Search Architecture

Instant lexical SQLite FTS5 search complemented by semantic conceptual queries with explanation scoring.

Bring Your Own AI

Connect Claude, OpenAI, Gemini, or local Ollama. Zero-AI disconnected mode guarantees lightweight purity.

Distraction-Free Reader

Sanitized HTML rendering with typography presets, zero ads, no trackers, and instant offline readability.

Clips & Recycle System

Nested hierarchical collections, non-destructive soft deletion, instant 6-second undo toast, and safe purge.

Single File Database

Self-contained SQLite WAL architecture. Simple backups, predictable performance, zero cloud lock-in.

Deployment

Deploy in 60 seconds

docker-compose.yml Docker 
services:
  slip:
    image: ghcr.io/akshaybhandare/slip:latest
    container_name: slip
    restart: unless-stopped
    ports:
      - "3000:3000"
    volumes:
      - ./data:/app/data
    environment:
      - PORT=3000
      - NODE_ENV=production
